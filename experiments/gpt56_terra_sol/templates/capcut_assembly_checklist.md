# CapCut evidence assembly checklist

- Target duration: 60–70 seconds.
- About 10 scenes.
- Proof/runtime evidence: at least 50% of duration.

## Required evidence

- [ ] official pricing/source capture
- [ ] test setup
- [ ] synthetic fixture
- [ ] model/effort capture
- [ ] raw output excerpts
- [ ] blind scorecard
- [ ] critical errors
- [ ] correction times
- [ ] result chart
- [ ] limitation card

## Assembly and export

- [ ] mostly hard cuts
- [ ] no generic AI background
- [ ] no stock as proof
- [ ] text-only scenes do not dominate
- [ ] source labels visible
- [ ] model identity hidden until result scene
- [ ] no private data
- [ ] no fabricated UI
- [ ] no Higgsfield-generated proof
- [ ] H.264/AAC, 1080×1920, 30 fps, no watermark
- [ ] owner approval before publication

Do not create or upload a CapCut project as part of harness preparation.
