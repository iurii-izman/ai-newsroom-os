# Blind review rubric

| Criterion | Points |
|---|---:|
| Factual accuracy | 0–2 |
| Root-cause reasoning | 0–1 |
| Idempotency | 0–1 |
| Timeout/retry/uncertain outcome | 0–1 |
| Assignment | 0–1 |
| Remediation plan | 0–1 |
| UAT coverage | 0–1 |
| Risks/assumptions | 0–1 |
| Practical usability | 0–1 |

Critical errors are counted separately. Use the private reference key only during human review.
Do not enter model identity into the score or correction files before analysis/unblinding.
